# تانل GRE بهینه (بر پایه vatanhost/gre)

## نصب
روی هر سرور (اول سرورهای خارج، بعد ایران) این را اجرا کنید:
```bash
bash <(curl -sSL https://raw.githubusercontent.com/tradeahadi-cmyk/gre-tunnel/main/gre-install.sh)
```
سؤال‌ها همان اسکریپت قبلی است، به‌علاوه:
- **Tunnel number:** برای آلمان 1، برای ترکیه 2 (روی هر دو طرفِ یک تانل باید یکی باشد).
- **Ports (فقط ایران):** پورت‌هایی که باید به این سرور خارج برود، مثلاً `8388,2053`. اگر فقط یک سرور خارج دارید، `all` همه‌چیز غیر از SSH را می‌فرستد (مثل اسکریپت قبلی).

اسکریپت خودش تانل قدیمی `vatan-m2` و قوانین iptables آن را پاک می‌کند.

## تست
```bash
gre-tunnel check 1                 # روی ایران یا خارج
systemctl status gre-tunnel@1
journalctl -t gre-watchdog         # ری‌استارت‌های خودکار
```

## حذف
همان دستور نصب و گزینه 2.
