# تانل GRE بهینه (بر پایه vatanhost/gre)

## نصب
روی هر سرور (اول سرورهای خارج، بعد ایران) این را اجرا کنید:
```bash
bash <(curl -sSL https://raw.githubusercontent.com/tradeahadi-cmyk/gre-tunnel/main/gre-install.sh)
```
- **Tunnel number:** برای آلمان 1، برای ترکیه 2. روی هر دو طرفِ یک تانل باید یکی باشد.
- **Ports:** پورت‌هایی که از ایران به این سرور خارج می‌رود، مثلاً `8388,2053` (بازه هم می‌شود: `20000:20100`). روی سرور خارج هم **همان لیست** را بدهید.
- روی ایران برای هر سرور خارج یک بار اجرا کنید. پورت دو سرور نباید تکراری باشد.
- `all` (همه پورت‌ها غیر از SSH) فقط وقتی مجاز است که ایران فقط یک سرور خارج داشته باشد.

اسکریپت خودش تانل قدیمی `vatan-m2` و قوانینش را پاک می‌کند، حتی اگر در rc.local یا crontab یا rules.v4 ذخیره شده باشد (از فایل‌ها نسخه `.bak` می‌ماند).

نسخه‌ها و تغییرات هر نسخه در [CHANGELOG.md](CHANGELOG.md) است. برای نصب یک نسخه مشخص، به‌جای `main` شماره نسخه را بگذارید (مثلاً `v2.0.1`).

## تست
```bash
gre-tunnel check 1                 # روی ایران یا خارج
gre-tunnel version                 # نسخه نصب‌شده
systemctl status gre-tunnel@1
journalctl -t gre-watchdog         # گزارش‌های واچ‌داگ
```

## حذف
همان دستور نصب و گزینه 2.

## چه چیزی عوض شده (نسبت به اسکریپت vatanhost)
- بعد از ریبوت خودکار بالا می‌آید (سرویس systemd).
- فقط پورت‌های انتخابی فوروارد می‌شود؛ بسته‌های GRE، ICMP و SSH هرگز فوروارد نمی‌شوند.
- روی سرور خارج فقط همان پورت‌ها از تانل پذیرفته می‌شود (سرویس‌های دیگر مثل پنل از طریق IP ایران باز نمی‌شوند). پینگ از بیرون بسته است.
- MTU برابر 1420 و MSS ثابت 1380، تا اتصال‌ها روی مسیرهای با MTU کمتر گیر نکنند.
- با ufw و Docker تداخل ندارد (GRE و فوروارد صریحاً مجاز می‌شود).
- جدول conntrack روی ایران بزرگ‌تر می‌شود تا با کاربر زیاد بسته‌ها دور ریخته نشوند.
- واچ‌داگ هر ۳۰ ثانیه: اگر چیزی (مثلاً `iptables -F`) قوانین یا تانل را پاک کرده باشد، دوباره می‌سازد. اگر سرِ دیگر جواب ندهد فقط در لاگ ثبت می‌کند و تانل را ری‌استارت نمی‌کند، چون ری‌استارت همه کاربران را قطع می‌کند و GRE را درست نمی‌کند.

## آی‌پی‌های تانل
| تانل | ایران | خارج |
|---|---|---|
| 1 | 10.200.1.2 | 10.200.1.1 |
| 2 | 10.200.2.2 | 10.200.2.1 |

## نکته‌ها
- سرور خارج همه کاربران را با IP `10.200.N.2` می‌بیند، پس «محدودیت IP» پنل کار نمی‌کند (در اسکریپت قبلی هم همین بود). اگر fail2ban دارید، `10.200.0.0/16` را در `ignoreip` بگذارید.
- برای تغییر MTU، مقدار `MTU=` را در `/etc/gre-tunnel/N.conf` روی هر دو طرف عوض کنید و `systemctl restart gre-tunnel@N` بزنید.
